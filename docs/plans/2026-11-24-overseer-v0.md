# overseer v0: rough plan

Architecture and its rationale: [ADR 0001](../adr/0001-v0-architecture.md).

## Workspace

```
crates/core     llm client, tools, agent loop, event types        (no axum, no db)
crates/store    graven EventStore over SQLite, session fold       (db only)
crates/server   axum routes, session manager, SSE, startup
crates/cli      headless REPL over core + in-memory store, for debugging the loop
crates/fake-llm scripted OpenAI-compatible endpoint replaying scenario files (test harness)
web/            React client
```

`core` emits events through an `EventSink` trait; `store` implements persistence; `server` wires persistence to the broadcast.

## Phases

| # | Phase | Done when |
|---|---|---|
| 0 | Scaffold: cargo workspace, `web/`, commit gate (fmt, clippy `-D warnings`, nextest, shear, deny; Biome, tsc, Vitest, Playwright), CI | gate green on an empty workspace |
| 1 | Streaming LLM client: SSE parser, `tool_calls` assembled from deltas by `index`, `finish_reason`, usage | fixture tests on documented provider streams pass; a real recording joins them in phase 3 |
| 2 | Tools + registry: JSON schemas, errors returned to the model as results, bash timeout kills the whole process group, output truncated | unit tests per tool; a timeout is proven to kill the background child, not just bash |
| 3 | Agent loop: history rebuilt from events, iteration cap, `CancellationToken` that also kills a running bash | mock-LLM tests for text, tools, failures, the cap and cancellation; the CLI binary runs a turn against a scripted endpoint |
| 4 | Store on graven: `crates/store`, append, read after a position, sessions folded from the log | the same test suite passes on SQLite and in-memory — see [phase 4 store plan](2026-11-24-phase-4-store-graven.md) |
| 5 | Server: session actors, `/api` routes, Host/Origin filter, SSE with replay, startup recovery, `embed-web` feature; `crates/fake-llm` and `just dev-mock` | integration test against the fake model: post a message, read the SSE stream, reconnect mid-turn, no gap or duplicate; cancel and restart leave no tool call without a result |
| 6 | OpenAPI spec from `utoipa`, client SDK + Zod schemas + Query hooks from `@hey-api/openapi-ts`, drift checked in CI | `web` build fails on protocol drift |
| 7 | Web client: session list, chat with streamed markdown, tool-call cards (args, exit, output), cancel, auto-reconnect; Storybook with one story per UI state, run as Vitest tests | every fake-model scenario rendered in `just dev-mock` and covered by a story; Playwright green on the scenarios |
| 8 | E2E smoke on a real repo, both backends | one task completed end to end in the browser |

## Still out of scope after the 2026-11-24 wishlist

Both wishlist batches landed. What remains is the product, not the polish:

- Server, SSE and chat UI (phases 5-7).
- Context compaction, tool approvals, Postgres-backed sessions.
- A real recorded fixture: `just record` is in place, but no key was available here.
